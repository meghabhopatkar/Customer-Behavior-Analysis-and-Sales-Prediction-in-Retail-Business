# Retail Sales Analytics, Customer Behavior Analysis and Sales Forecasting

## Project Overview

This project focuses on analyzing retail supermarket sales data to generate business insights, understand customer purchasing behavior, and forecast future sales trends. The solution combines data warehousing, data analytics, machine learning, and business intelligence techniques to support data\-driven decision\-making.

## Objectives

- Analyze sales performance across products, branches, and cities.
- Understand customer purchasing behavior and spending patterns.
- Compare Festival and Non\-Festival product performance.
- Identify top\-performing product categories and revenue drivers.
- Forecast future sales using machine learning models.
- Build an interactive Power BI dashboard for business reporting.

## Features

- Data Storage using SQL Data Warehouse
- Data Cleaning and Preprocessing with Python
- Exploratory Data Analysis (EDA)
- Customer Behavior Analysis
- Revenue and Product Performance Analysis
- Festival vs Non\-Festival Product Comparison
- Sales Forecasting using Machine Learning
- Interactive Power BI Dashboard
- Business Insights and Recommendations

## Technology Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit\-Learn
- MySQL
- Power BI
- Jupyter Notebook

## Machine Learning Models

- Linear Regression for Sales Forecasting
- Random Forest Regressor for Revenue Prediction

## Dashboard Insights

- Total Revenue
- Total Transactions
- Average Rating
- Product Performance
- Branch Performance
- Customer Segmentation
- Payment Method Analysis
- Festival vs Non\-Festival Analysis
- Revenue Trends and Forecasts

## Expected Outcomes

The project enables retailers to understand customer preferences, improve product strategies, optimize sales performance, and make data\-driven business decisions using analytics and forecasting techniques.
